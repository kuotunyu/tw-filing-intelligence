# v1.0.2 Repository Closeout Design

`status: implementation verified; publication pending`

## Objective

Publish one final presentation-only patch release that removes release-state drift,
improves citation and license metadata, and makes the next release immutable without
changing any research input, model output, score, threshold, or verdict.

## Frozen boundary

The following artifacts are read-only for this closeout:

- `docs/FEASIBILITY_PROTOCOL.md` and `results/feasibility/protocol_lock.json`
- `data/evaluation/dev/` and `data/evaluation/locked/`
- `results/runs/F0/` through `results/runs/F7/` and `results/runs/probes/`
- `results/feasibility/summary.json`, `error_analysis.jsonl`, and `GO_NO_GO.json`
- model pins, tolerances, gates, and the `NO_GO` conclusion

No model evaluation, API-backed inference, retrieval rebuild, threshold selection, or GPU
work is part of v1.0.2.

## Documentation state hierarchy

The current source of truth is, in order:

1. `README.md` for public scope and navigation.
2. `docs/FEASIBILITY_REPORT.md` for the locked result and limitations.
3. `docs/FEASIBILITY_PROTOCOL.md`, its lock, and the committed raw records for frozen evidence.
4. `CHANGELOG.md` and the latest GitHub release for repository release state.

`HANDOFF.md`, `PROGRESS.md`, `IMPLEMENTATION_PLAN.md`, and dated Superpowers plans are historical
records. They remain committed for research-process transparency but receive an archive banner;
their old instructions must not be executed as current work.

Active agent instructions in `CLAUDE.md` and `.claude/skills/twfi-repo-guardrails/SKILL.md` are
updated to enforce Feature Freeze and the source-of-truth hierarchy.

## Release integrity

Changes are developed on `codex/twfi-v1.0.2-closeout`, reviewed through a pull request, and
merged only after both CI jobs pass on the exact branch SHA. Repository release immutability is
enabled before publishing v1.0.2, because GitHub applies that setting only to future releases.
The existing v1.0.1 tag is never moved or rewritten.

v1.0.2 remains source-only: no PDFs, indexes, databases, model weights, wheels, hosted demo, or
production service are published.

## Non-goals

- No new retrieval, reranker, router, Agent, VLM, prompt, model, or evaluation run.
- No claim that the prototype is a production filing assistant.
- No cleanup that deletes local PDFs, indexes, caches, or historical research records.
- No retrospective substitution of F5 for the registered F7 candidate.
