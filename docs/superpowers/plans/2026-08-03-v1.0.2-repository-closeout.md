**Goal:** Prepare a source-only v1.0.2 presentation and governance closeout for reviewed release
without changing frozen research evidence or running models.

**Architecture:** Keep the research lineage immutable and change only release metadata,
human-facing navigation, active agent instructions, and GitHub repository settings. Validate the
release version through an existing repository invariant, then independently re-run every offline
evidence and quality check before publishing.

**Tech Stack:** Markdown, Citation File Format 1.2.0, Python 3.13, pytest, Ruff, mypy, uv, GitHub
Actions, GitHub Releases.

## Global Constraints

- Preserve Protocol 1.0.0, locked gold/probes, model pins, thresholds, raw run records, and
  `NO_GO` exactly.
- Do not call model APIs, run inference, use a GPU, rebuild retrieval, or publish binary assets.
- Do not read or display `.env` values.
- Do not move or rewrite v1.0.1.
- Keep all public text explicit that this is research, not investment advice or production.

## Post-merge release procedure

This procedure is executed against GitHub after the reviewed implementation plan above is complete.
Its authoritative completion record is the immutable GitHub release rather than a checkbox that
would require a post-release source commit.

1. Push the branch and create a pull request against `main`. Require both `Python quality checks`
   and `Recompute committed research evidence` to pass on the exact branch SHA.
2. Merge without rewriting history. Use a merge commit, verify the merge tree equals the reviewed
   feature tree, and wait for main CI.
3. Add focused repository topics and confirm GitHub reports the license as MIT.
4. Enable repository release immutability before creating the release. Create an annotated v1.0.2
   tag at the exact green merge SHA and publish a source-only release with no uploaded assets.
5. Confirm the release is latest, immutable, not draft/prerelease, points to the merge SHA,
   preserves v1.0.1 unchanged, and accurately reports clean-clone versus local-raw test counts.
